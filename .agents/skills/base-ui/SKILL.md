# Base UI

Use Base UI's official documentation as the source of truth before implementing, reviewing, or debugging Base UI components.

Start with the [Base UI documentation index](https://base-ui.com/llms.txt), then open the relevant linked component or handbook page. Confirm APIs against the project's installed Base UI version when version differences may matter.

Prefer the library's documented props and behavior over custom state, event handlers, timers, or accessibility logic.
